## 📋 About
The **RUET Course Registration Form Generator** is a specialized web application designed specifically for students of **Rajshahi University of Engineering & Technology (RUET)** to generate their course registration forms in the official university format.

The tool automates the process of creating registration forms, ensuring compliance with RUET's official formatting requirements while providing an intuitive and user-friendly interface.

## ✨ Features
| Feature | Description | Icon |
|---------|-------------|------|
| **Smart Course Search** | Quickly find courses by code or title with intelligent autocomplete suggestions | 🔍 |
| **Automated Calculations** | Automatic total credit calculation as you add courses | 🧮 |
| **Real-time Preview** | Instant PDF preview before downloading | 👁️ |
| **Easy Course Management** | Add or remove courses with single clicks | ✅ |
| **Backlog Course Tracking** | Dedicated section for backlog courses | 📚 |
| **Official Format** | Generates PDF in RUET's official registration form format | 🏛️ |
| **Comprehensive Database** | Pre-loaded with courses from all Engineering Departments | 🗃️ |

```plaintext
1. Open the registration form generator
2. Enter your student information
